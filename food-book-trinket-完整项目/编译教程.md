# Food Book Trinket 编译教程（得到可执行 Jar 文件）

> 目标产物：`build/libs/foodbooktrinket-1.0.0.jar`，直接拖进游戏 `mods` 文件夹即可。

## 一、你需要准备的环境

1. **JDK 17**（必须，Forge 1.20.1 需要 17；本机是 21 也能编译但 17 最稳）
   - 下载：<https://adoptium.net/temurin/releases/?version=17>
   - 装好后记下安装路径，例如 `C:\Program Files\Eclipse Adoptium\jdk-17.0.x-hotspot`
2. **IntelliJ IDEA**（推荐，社区版免费）或已安装的 Gradle 8.x
3. 稳定的网络（首次编译要下载大量依赖）

## 二、方式 A：用 IntelliJ IDEA（推荐，最简单）

1. 打开 IDEA → `File` → `Open` → 选中本项目根目录（含 `build.gradle` 的文件夹）
2. IDEA 弹出提示时选择 **"Trust Project"**（信任项目）
3. 等 IDEA 自动下载 Gradle 和依赖（右下角进度条，可能要几分钟到几十分钟）
4. 如果 IDEA 用错了 JDK：
   - `File` → `Project Structure` → `Project` → 把 SDK 改成 **17**
5. 打开右侧 **Gradle 面板**（小象图标）→ 展开 `Tasks` → `build` → 双击 **`build`**
6. 等待完成后，产物在 `build/libs/foodbooktrinket-1.0.0.jar`

## 三、方式 B：命令行（需已装 Gradle 8.x 或补齐 wrapper）

### 若已安装 Gradle：
```bash
# 在项目根目录
gradle build
```

### 若想用 wrapper（本机没有 gradle-wrapper.jar，需先补一个）：
```bash
# 在任意装了 Gradle 的机器上，于项目根目录执行一次即可生成 wrapper：
gradle wrapper --gradle-version 8.7

# 之后就能直接：
./gradlew build        # Linux / Mac
gradlew.bat build      # Windows
```

## 四、设置 JAVA_HOME（命令行方式必需）

Windows 示例（PowerShell，按你实际路径改）：
```powershell
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-17.0.12.7-hotspot"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
```

## 五、常见问题

| 现象 | 解决 |
|------|------|
| 报 `Java 版本不符` | 确认 JAVA_HOME 指向 JDK 17，不是 21 |
| 下载依赖卡住/超时 | 换网络/梯子；国内可给 `gradle.properties` 加镜像源 |
| 报 Curios 依赖找不到 | 确认网络能访问 `maven.theillusivec4.top`，这是 Curios 官方仓库 |
| `mods.toml` 展开失败 | 确认 `gradle.properties` 里的变量名与 `mods.toml` 占位符一致 |

## 六、装进游戏

1. 准备 Minecraft 1.20.1 + Forge 47.4.28 客户端
2. 下载 **Curios API**（`curios-forge-1.20.1-5.4.7`）放进 `mods` 文件夹
   - 下载地址：<https://www.curseforge.com/minecraft/mc-mods/curios>
3. 把编译出的 `foodbooktrinket-1.0.0.jar` 也放进 `mods`
4. 启动游戏，用 `/give @p foodbooktrinket:food_book` 获取食物之书
5. 打开角色界面（默认按键打开 Curios 界面），把书放进 **配饰(charm)** 栏位
6. 吃各种没吃过的新食物，每次攻击力 +0.2
